# Bandit Levels 32–33: Special Shell and Final Challenge

## Level 32 → 33: Understand a Restricted Shell

**Goal:** Observe how a custom shell behaves and learn that it may handle commands differently from a normal Linux shell.

Useful commands to review:

```bash
whoami
pwd
ls
```

- `whoami` displays the current username.
- `pwd` displays the current working directory.
- `ls` lists files and directories.

**Key takeaway:** A shell controls how commands are interpreted. A restricted or custom shell may behave differently from Bash.
