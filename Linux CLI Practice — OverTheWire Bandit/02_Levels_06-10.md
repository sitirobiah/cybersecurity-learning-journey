##Overview: Levels 6–10

##In these levels, I learned different Linux command-line techniques for finding files, searching text, identifying unique lines, extracting readable strings from binary data, and decoding Base64-encoded content.

##These exercises helped me understand how to use commands such as find, grep, sort, uniq, strings, and base64 to locate and analyze information in files.

## Level 6: Search by ownership and size
```bash
find / -type f -user bandit7 -group bandit6 -size 33c 2>/dev/null
```
- `/` starts the search from the filesystem root.
- `-user` and `-group` filter by owner and group.
- `2>/dev/null` hides error messages such as permission-denied warnings.

## Level 7: Search text in a file
```bash
grep "millionth" data.txt
```
- `grep` finds lines matching a word or pattern.

## Level 8: Find a unique line
```bash
sort data.txt | uniq -u
```
- `sort` puts matching lines together.
- `uniq -u` prints lines that occur only once.
- `|` sends one command's output to the next command.

## Level 9: Read human-readable strings from binary data
```bash
strings data.bin
```
- `strings` prints readable text found inside a file.

## Level 10: Decode Base64
```bash
base64 -d data.txt
```
- `base64 -d` decodes Base64-encoded data.
- Encoding is not the same as encryption.
