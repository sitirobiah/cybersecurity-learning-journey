# Bandit Levels 27–29: Git Basics

## Level 27 → 28: Clone a Repository

**Goal:** Learn how to copy a remote Git repository.

```bash
git clone <repository_url>
cd <repository_name>
```

- `git clone` downloads a repository and its available history.
- `cd` moves into the downloaded directory.

**Key takeaway:** Cloning creates a local copy of a Git repository.

## Level 28 → 29: Inspect Repository History

**Goal:** Explore commits and review project history.

```bash
git log
git show
git status
```

- `git log` displays commit history.
- `git show` displays details about a commit or Git object.
- `git status` shows the current working tree state.

**Key takeaway:** Git history can contain information that is not visible in the current version of a file.

## Level 29 → 30: Inspect Branches and Remote Information

**Goal:** Learn how to inspect repository branches and remotes.

```bash
git branch -a
git remote -v
git log --all --oneline
```

- `git branch -a` lists local and remote-tracking branches.
- `git remote -v` displays configured remote repositories.
- `git log --all --oneline` summarizes commits reachable from the available references.

**Key takeaway:** A repository may contain different branches and histories. The current branch may not contain every relevant change.

> Note: The commands above are useful for exploring Git repositories. Use the specific challenge instructions to determine which information is relevant at each level.
